Pixel Ruler

Privacy Policy

Last updated: September 16, 2026

Pixel Ruler is a browser extension that measures distances, element sizes and spacing on a web page. This policy describes exactly what it does with data — which is nothing.

What the extension collects

Nothing. It does not collect, transmit, store on any server, sell or share any personal data, browsing history, page content or usage statistics. There are no accounts, no sign-in, no tracking and no analytics inside the extension.

Network requests

The extension makes no network requests at all. Everything it runs ships inside the package: no remote code, no content delivery networks, no remote fonts. You can verify this yourself — open DevTools, switch to the Network tab and use the ruler.

What it reads on a page

Only geometry. To draw dimension lines the extension asks the browser where elements are and how big they are (getBoundingClientRect, getComputedStyle). It does not read page text, form fields, passwords or cookies, and it does not send the address of the page anywhere.

When it runs

Only when you ask. The extension declares no host permissions and installs no permanent scripts, so it is absent from every page until you click its toolbar icon or press its keyboard shortcut. That click grants Chrome's activeTab permission for that one tab, and the overlay is removed completely when you press Esc or navigate away.

What stays in your browser

  • Settings — four on/off switches, in chrome.storage.sync (or local when sync is off), so they follow your Chrome profile.
  • A first-run flag — remembers that the introduction card was shown.
  • Your last measurement — width, height and coordinates, in chrome.storage.session. It never reaches the disk and is cleared when the browser closes.

All of it is deleted when you remove the extension.

Third parties

None. The extension contains no third-party libraries that run at runtime, no advertising and no affiliate code. This website (the welcome, removal and policy pages) is served by GitHub Pages and may carry basic visit statistics; the extension itself does not.

Children

The extension is a developer tool and is not directed at children. Since it collects no data at all, it holds no information about anyone, of any age.

Changes

If this policy ever changes, the new version appears on this page with a new date. A change that would start collecting data would also require new permissions, which Chrome shows you before the update installs.

Contact

Questions about this policy: write through the support link on the Chrome Web Store listing.
